Add a station

New kinds of station are rows, not code. Add a VR arena and it is on the floor, in the rate card and in the day sheet immediately.

Billing rules

One place, applied to every station and shown on the guest's running total:

  • The bill is the rate spread over the minutes actually played.
  • Any started minute counts in full, so 61 seconds is two minutes.
  • The rate is copied onto the session at start, so a later price change never rewrites yesterday.
  • Happy-hour and weekend rates attach to a station kind and a time window.

How it gets built

The console lives inside the existing v2 site at /admin, so there is one deploy, one domain and one set of brand styles.

Stack

  • Next.js App Router, server actions — same app, new /admin area.
  • Postgres (Neon or Supabase, free tier is plenty) with Drizzle for migrations.
  • Session cookies signed server-side; Argon2id password hashes.
  • Runs on the Hostinger Node app you already deploy to.

Why a database, not a spreadsheet

  • Two phones can run the floor at once without overwriting each other.
  • A crashed tab or a dead battery loses nothing — the timer is a start time on the server.
  • Closed days cannot be quietly edited.
  • Reports are a query, not a copy-paste.

How a timer actually works

  • Start writes started_at on the server; the browser only counts up from it.
  • Any device opening the floor sees the same elapsed time.
  • Stop computes the bill on the server from the stored rate and rules.
  • Pressing stop twice cannot double-bill: the session is already closed.

Order of work

Phase 1

Login, floor, timers

Staff sign-in, the station grid, start and stop with live timers, automatic billing, today's takings. This is the part that replaces the notebook, and it is usable on its own.

Phase 2

Day sheet and closing

The day's sessions, cash versus UPI split, close-the-day lock, and a month view with busiest hours and per-station utilisation.

Phase 3

Guests and offers

Phone-number lookup, visit counts, 10-hour passes tracked against a balance, birthday and party bookings held against a station and a time.

Phase 4

Tie it to the public site

Live "3 bays free right now" on the home page, WhatsApp receipt after a session, and a booking request that lands in the console instead of a chat thread.
